# Mixed-team formative pilot

The user confirmed “A mix of researchers and general teammates” on October 13.
This specifies the planned participant mix; it is not evidence that anyone has
completed a test or has verified a scientific result.

Use the existing [E6 protocol](BENCHMARKS.md#e6--scientist-usefulness-and-reproducibility).
Report researcher and general-teammate results separately. General navigation
feedback cannot establish environmental classification accuracy. Researchers'
opinions also do not replace independently reviewed reference labels.

Freeze equivalent cases and tasks before collecting responses. Include a clear
recorded change, an ambiguous interpretation and an explicit abstention. A radar
backscatter change may serve as the ambiguous case; do not rename it a confirmed
water or damage footprint. A past target whose interval ended before receipt can
serve as a timing abstention. Independently reviewed environmental case labels
remain a separate prerequisite.

Counterbalance the existing viewer and evidence-brief workflows across equivalent
cases; record case identifiers, source hashes and which order each participant
received. Do not use the same answer twice as if the second attempt were untrained.

For each task, record an anonymous participant code and self-reported background,
completion time, source-recovery success, unsupported conclusions, corrections,
and whether the participant can identify unknown support and reproduce a stated
measurement. Score inspection priorities against independent references only when
those references exist. Leave unavailable scores unknown rather than assigning
zero error.

Start with a small formative pilot. Preserve all attempts and failures, and report
observed counts and descriptive times by participant group and workflow. No
population-level significance or environmental accuracy claim follows automatically.
Participation and actual task results remain pending; this document is a protocol,
not a completed study. It adds no automatic telemetry, external sharing or account
changes.
