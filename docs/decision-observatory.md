## Shared implementation contract (version 1.0)

The coordinator maintains `lib/observatory-contract.ts`. New Python code uses the equivalent plain JSON contract below. No external client may submit measurements or claims as authoritative evidence.

Assessment request: `{schemaVersion:"1.0", domain:"water"|"fire"|"ecology"|"urban", question:"change"|"seasonal"|"explain"|"exposure"|"future"|"options", area:{type:"Polygon"|"MultiPolygon",coordinates:...}, start:"YYYY-MM-DD", end:"YYYY-MM-DD", options?:{sourceIds?:string[],gaugeId?:string,referenceStart?:string,referenceEnd?:string}}`. Geometry: WGS84, maximum 512 positions, 16 polygons, 16 rings per polygon, closed nonempty rings, holes supported, latitude ±85 for processing; longitude ±180 with explicit antimeridian handling. Reject invalid/self-intersecting rings and holes outside shells. Body remains bounded at 16 KiB. Search boxes split across the antimeridian; calculations use the original recorded geometry.

Assessment result: `{schemaVersion:"1.0",kind:"assessment",domain,question,area,time:{start,end},processedAt,methodVersion,title,outcome:"complete"|"partial"|"unavailable",evidence:EvidenceRecord[],claims:Claim[],metrics:Metric[],quality:QualityOutcome[],brief:Brief,artifacts:string[]}`.

EvidenceRecord: `{id,sourceId,sourceVersion,title,url,geometry:GeoJSON|null,spatialSupport:{resolution:number|null,unit:string,description:string},timestamps:{observedStart:string|null,observedEnd:string|null,publishedAt:string|null,retrievedAt:string,validThrough:string|null},quantity:string,unit:string,quality:{commonCoveragePercent:number|null,notes:string[]},maskPolicy:string,methodVersion:string,hashes:Record<string,string>,public:boolean}`. Unknown timestamp or coverage stays null; public false for private crop artifacts even when upstream source is public.

Claim: `{id,type:"Observed"|"Derived"|"Possible explanation"|"Forecast"|"Scenario"|"Human annotation",text,evidenceIds:string[],methodVersion,assumptions:string[],uncertainty:string[],applicability:string[],counterevidence:string[]}`. Every brief section refers to claim IDs only. Do not publish unsupported causal attribution or whole-area interpretation below 80% common valid coverage. The threshold is an initial product gate.

Metric: `{id,label,value:number|null,unit,evidenceIds:string[],description,denominator:string|null}`. QualityOutcome: `{dimension:"coverage"|"measurement"|"attribution"|"prediction"|"transfer"|"freshness",status:"supported"|"limited"|"withheld"|"unknown",message}`. Brief: `{title,sections:[{id:"changed"|"meaning"|"future"|"options"|"unknown",title,claimIds:string[]}]}`.

Engine interface: `service.observatory.engine.run_assessment(request, config, output)` returns the result dictionary and writes exactly `manifest.json`, `brief.json`, `metrics.csv`, `area.geojson`, `evidence.json`. Source adapters must use bounded HTTPS allowlisted provider fetches, no arbitrary client URL, no full-granule fallback. Record source retrieval/IDs/hashes and mask rules; explicit partial/unavailable output is valid if missing evidence is identified. Optional comparisons publish up to two measured quantities with four native GeoTIFFs and four protected PNG previews each, fixed filenames, hashes, shared display scales and independently reconciled exclusion masks.

Scenario request: `{schemaVersion:"1.0",assessmentId:string,kind:"threshold"|"footprint"|"options",inputs:{metricId?:string,threshold?:number,operator?:"above"|"below",footprints?:[{id,name,geometry:GeoJSON,cost?:number,benefit?:number}],weights?:{cost:number,benefit:number}},assumptions:string[],objectives:string[]}`. Engine: `run_scenario(request, assessment_result, config, output)` returns `{schemaVersion:"1.0",kind:"scenario",assessmentId,scenarioKind,methodVersion,changedInputs,assumptions,objectives,outputs:Metric[],sensitivities:string[],alternatives:[{id,name,cost:number|null,benefit:number|null,pareto:boolean|null,score:number|null}],claims:Claim[],limitations:string[],artifacts:string[]}`. Unknown effects/costs stay null; supplied benefit is an assumption, never an observed effect. No scenario probabilities.

Queue integration: migrate jobs with `kind` default `radar`; old API/list/wire remains compatible and filters radar. New assessments/scenarios share all admission, heartbeat, cancellation, restart, expiry, disk, runtime and transfer limits. New wire jobs: `{schemaVersion:"1.0",kind:"assessment"|"scenario",id,status,phase,createdAt,updatedAt,request,result,error}`. Keep job ownership independent of cache reuse. Scenario parent must belong to its creator (prepared public parent may be explicitly allowed without exposing other private jobs). Never publish partial files.

Interfaces: signed service `/api/sources`, `/api/assessments` POST/GET, `/api/assessments/:id` GET, `/:id/cancel` POST, `/:id/brief` GET, `/:id/artifacts/:name` GET; `/api/scenarios` POST/GET and `/:id` GET/cancel/artifacts for UI history. Snapshot endpoint may persist compact owner-scoped manifests separately from seven-day raster artifacts. Web `/api/assistant` uses only a separate public reviewed registry, explicit consent and preview; private results remain deterministic locally.
