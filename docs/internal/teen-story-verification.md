The optional investigation has a single player-led question: a city looks still, but
its ground-motion pattern needs explaining. The opening action reveals the
existing frozen scene's colours with a short illustrated sweep. It does not
request or simulate a new radar acquisition. Five visible, unrestricted clue
nodes stay in the header; the case file is available from the beginning.

The old closed quiz disclosures no longer carry the main story challenges.
Each chapter has a different action: order a simplified pumping/pressure/
compaction chain, compare the ends of three invented streets, test the existing
radar model at zero sinking, classify observation/scenario/unsupported claims,
and combine withdrawal control with repeat monitoring. Retry feedback explains
the specific mistaken relation. Earned findings appear in both the chapter and
case file. Existing local receipts award once, preserve prior progress, handle
storage failure and retain their original version and concurrency behaviour.
Points describe game progress, never scientific confidence.

The aquifer and invented-city chapters have explicit still-state buttons and
one requested 2.2-second “Watch the change” sequence. Only one short narrative
beat is shown at a time. Manual stills remain usable during pause/reduced motion.
The simulation's new manualProgress option does not change existing scroll or
measured-city authority. Chapter playback cancels on pause, reduced motion,
visibility loss, offscreen state, explicit stop/seek/replay and teardown; queued
stale callbacks cannot revive it. No idle clock is introduced. The radar task
is embedded beside the existing model controls, without a second experiment.

The final case file distinguishes mechanism, invented street, synthetic radar,
provisional observations and historical context. It collects earned findings and
asks for a defensible headline, with an unresolved question and follow-up evidence.
A progress reset clears transient tasks and a filed conclusion; hiding challenges
keeps progress and access to the story. Measured quantities, source files,
uncertainty, projection caveats, routes and authentication are unchanged.
