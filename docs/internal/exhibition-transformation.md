## Audit and implementation

The current implementation already had manual experiments rather than quiz
forms. Its weakness was shallow completion, broad canned feedback and generic
postcards. Extend those shared worlds instead of adding a second playable set.

| Files | Implemented responsibility |
| --- | --- |

| `field-investigation`, `FieldInstruments` | Four finite drought seasons; conserved authored water units, irreversible compaction pose, demand and another supply. Separate fictional timing scenario, not a policy-effect estimate. |

## Research that influenced the implementation

- [PhET research](https://phet.colorado.edu/en/research) and the
  [implicit-scaffolding paper](https://arxiv.org/abs/1306.6544): make a productive
  action obvious and let feedback expose the relationship. This is a design
  basis, not evidence that Earthsignal has been tested with teenagers.
- [NASA Eyes](https://science.nasa.gov/eyes/): an instrument and a coherent world
  can carry exploration; avoid introducing its breadth into the first minute.
- [Exploratorium Tinkering Studio](https://www.exploratorium.edu/tinkering): agency
  and personally meaningful artifacts; keep the player's evidence, not an exam.
- [Bret Victor's ladder of abstraction](https://worrydream.com/LadderOfAbstraction/):
  connect a concrete point to the wider trajectory. The radar probe and paired
  section use this relationship.
- [NASA interferometry](https://science.nasa.gov/mission/nisar/interferometry/) and
  [USGS pumping-induced subsidence](https://pubs.usgs.gov/sir/2007/5251/section4.html):
  preserve LOS projection, cyclic ambiguity and the distinction between elastic
  and inelastic behaviour. The game does not calibrate a constitutive law.
- The fresh official challenge fetch returned 502. That is not evidence of an
  unpublished brief: the earlier [research audit](alive-story-research.md)
  records the inspected official flight payload. No invented rubric or prize
  guarantee is used.

## Invariants and checks

`radar-interferometry.ts`, `public-radar-study.ts`, `story-evidence.ts`, bundled
measurements, masks, source hashes and design tokens are unchanged. A colour-scale
limit of -250 mm/yr is not a measurement. The -307.9 mm/yr figure is the manifest's
selected 1.2 km neighbourhood aggregate. A rate is not a full year of observed
height loss. Missing/excluded readings carry their own stamps; neither a large
nor unresolved ground tilt diagnoses a building.

The full run passed 367 tests. Follow-up focused checks passed for the final
phase/baseline rendering and local notes changes. Typecheck passed; lint reported
zero errors and 12 existing warnings. Production builds passed. New tests exercise resource conservation, exact
phase equality, actual data proofs, closed telemetry, consent payloads, local
reset, idle cancellation and recorded reactive audio. No blanket lint exception.

Optional browser commands use an already-installed official Playwright module
and WebKit executable, without installing runtime dependencies:

```sh
node scripts/verify-story-sticky.mjs /absolute/playwright/index.mjs BASE_URL /absolute/pw_run.sh
node scripts/verify-field-investigation.mjs /absolute/playwright/index.mjs BASE_URL /absolute/pw_run.sh
```

Artifacts go under ignored `output/playwright/`. WebKit 18.2 phone-preset checks
are automated engine coverage, **not a physical iPhone, UIKit toolbar, speaker
audibility or teen usability study**. Release receipts record the actual command,
URL, commit and outcome rather than implying hardware certification.

The final local production playthrough completed all five missions, retained nine
scalar readings, requested no assistant API, and loaded five recorded audio assets
only after consent. The mobile HUD fit within 80 px; the desktop companion stayed
in a 270 px sticky rail. A separate WebKit 18.2 regression passed forward/backward
scrolling across all three sticky chapters, with normal-flow landscape and
reduced-motion fallbacks. Mobile dossier and desktop street screenshots were
inspected before release.
